Traitement de Timbres

Déposez vos scans de timbres et de documents : le logiciel les détoure, les redresse et les place sur un fond noir avec une marge de 1 mm, sans toucher à leurs couleurs.

Télécharger le logiciel (.zip)

Toujours la dernière version, pour Windows.

Installer

  1. Installer Python 3.12Depuis python.org, version 3.12, « Windows installer 64-bit ». À faire une seule fois par ordinateur.
  2. Décompresser le zipClic droit sur le fichier téléchargé, puis « Extraire tout ».
  3. Lancer INSTALLER.batDouble-clic. Il prépare le logiciel et ses bibliothèques. Attendez le message « Installation terminée ».
  4. Traiter vos scansCopiez vos fichiers TIFF dans le dossier input, puis double-cliquez sur LANCER_TRAITEMENT.bat. Les résultats arrivent dans output.

Ce qu'il fait

  • Retire le fond gris du scanner autour de chaque élément, au pixel près, dentelures comprises.
  • Sépare les éléments posés côte à côte sur un même scan : un fichier par élément.
  • Redresse chaque élément sans le déformer ni créer de lignes de décalage.
  • Ajoute une marge noire de 1 mm, calculée d'après la résolution du scan.
  • Conserve les couleurs d'origine et vérifie chaque fichier produit ; les cas douteux sont signalés pour une reprise à la main.
